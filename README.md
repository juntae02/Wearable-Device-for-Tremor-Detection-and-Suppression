## 📌 주요 기능
- **주조 공정 자동화** : 용탕 주입, 용탕 균일화 등 주조 과정에서의 반복적이고 위험한 작업을 협동로봇이 수행하는 기능
- **단조 공정 지원** : 수평/수직 연마, 재련, 비틀기 등 단조 과정의 특정 작업을 협동로봇이 보조하는 기능
- **안전 기능 구현** : 충돌 감지 및 용탕 튐 방지와 같은 위험 요소를 사전에 방지하는 기능
- **QC 무게 측정** : 생산된 제품의 무게를 측정하여 품질을 관리하는 기능
- **TCP 통신 기반 제어** : 휴대폰과의 TCP 통신을 통해 로봇을 제어하고, 공정 상태를 모니터링할 수 있는 기능
